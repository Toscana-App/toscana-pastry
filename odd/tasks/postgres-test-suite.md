S4. Inserts must respect foreign keys on Postgres: a parent row is persisted before its children in the same transaction. Observed failures: `insert or update on table "calc_material_cost_history" violates foreign key constraint` (55 occurrences, `sql_calc_material_repository.py:162`) and `insert or update on table "calc_product_materials" violates foreign key constraint` (`sql_calc_product_repository.py:461`).
S5. Timezone-aware datetimes must be stored without error. Observed failure: `invalid input for query argument $5: datetime.datetime(...) (can't subtract offset-naive and offset-aware datetimes)` (`sql_order_repository.py:134`). Columns declared as naive `DateTime` in `backend/src/data/models.py`: `UserORM.created_at:54`, `BusinessSettingsORM.updated_at:78`, `CalcSettingsORM.updated_at:130`, `OrderORM.date:547`, `OrderORM.paid_at:554`, `OrderWindowORM.reopens_at:588`.
S6. Deleting a product category used only by soft-deleted products must not fail with a 500. Observed failure: `update or delete on table "calc_product_categories" violates foreign key constraint "calc_products_product_category_id_fkey"` in `test_calc_products_api.py::TestCountInUse::test_product_category_freed_by_deleted_product`.
S7. Failures that also happen on SQLite (not caused by Postgres) are triaged separately, one task per root cause. They are listed in T6 to T10.
